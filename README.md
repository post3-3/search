# 3+3 郵遞區號查詢器

輸入台灣地址，查詢中華郵政 3+3 郵遞區號，並產生標準中文地址與英文地址。

## 功能

- **單筆查詢**：輸入地址，取得 3+3 郵遞區號、標準地址、英文地址
- **批次查詢**：貼上多筆地址，或上傳 Excel（.xlsx / .xls）、CSV、TXT 檔，結果可複製貼回 Excel
- **查詢紀錄**：保存在瀏覽器本機
- 支援單雙號、連續號、巷弄、附號（之○號）、樓層等投遞範圍規則
- 自動校正路名錯字、舊縣市名稱（如臺北縣板橋市 → 新北市板橋區）、寫錯行政區的地址

## 使用

直接開啟 `index.html` 即可，所有資料都已內建，不需要伺服器。

## 資料來源

[中華郵政 3+3 郵遞區號](https://www.post.gov.tw/post/internet/Postal/index.jsp?ID=208) 轉碼軟體資料檔。
本工具非中華郵政官方服務，重要郵件寄出前請以中華郵政官網為準。

## 更新資料

中華郵政發布新版轉碼軟體後，將安裝目錄下 `DBF` 資料夾中的 `rall1.dbf`、`uroad.dbf`、`Ver.txt` 取出，執行：

```bash
python tools/build.py <DBF 資料夾路徑>
```

會重新產生 `index.html`。記得同時修改 `tools/template.html` 中的「更新日期」。
